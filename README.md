# Carbon-Footprint-Mini-Study-6-month-household-Carbon-footprint-
**Portfolio Project | Carbon Accounting & ESG Analysis**
This project analyses a 6-month household carbon footprint using real consumption data to quantify emissions across Scope 1–3 categories. The study was designed to simulate real-world carbon accounting and policy analysis, with a focus on identifying key emission drivers and actionable reduction strategies. 
# Aims 
- Quantify household carbon emissions across multiple categories.
- Identify high-impact emission drivers using data analysis.
- Apply DEFRA/BEIS emission factors to real-world data.
- Develop data handling, modelling, and visualisation skills.
- Build a foundation for larger-scale ESG and sustainability projects.

# Motivation
This project was undertaken to:
- Develop practical experience in environmental/carbon data analysis.
- Bridge the gap between academic theory and real-world application.
- Expand on core skills in Python, R, and Excel for sustainability analytics.
It served as a first large-scale independent project, leading into more advanced ESG analysis work.

# Methodoloy
Data Collection:
- Collected 200+ data points over a 6-month period
Categories included:Energy consumption | Transport | Food | Household activities

# Repo Structure 
- 1 Full Excel Dashboard with Data inputs, Calculations, Trend Visualisations etc.
- 1 Sensitivity Analysis Excel Dashboard with visualisations and trend identification
- 2 R scripts for Emissions Plots by Category and Emissions Over time (sensitivity analysis)
- 2 Pings depicting the above

# Emissions Calculation
Applied UK Government DEFRA/BEIS emission factors (2024)
Calculated emissions across: Scope 1 (direct emissions) / Scope 2 (electricity) / Scope 3 (indirect emissions)

# Analysis 
Performed: Trend analysis, Category-level emission breakdowns, Sensitivity analysis using low/high emission factor ranges.
Identified key drivers contributing disproportionately to total emissions.
Created charts and dashboards using: Excel and R.

# Key Findings
- A small number of categories contributed the majority of emissions/
- Emissions showed non-linear behaviour depending on consumption patterns.
- Sensitivity analysis highlighted uncertainty ranges in emission factors.
- Identified realistic interventions capable of achieving ~25% emission reduction

# Outcome
This project demonstrates:
- End-to-end data analysis workflow.
- Application of carbon accounting frameworks.
- Ability to translate data into policy-relevant insights.
